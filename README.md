Entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5)
bounty on make.fun: a program that writes one dad joke (at most 200
characters) to `/output/entry.txt`.

## The joke

> I told my son the bookmark is my best friend. He asked why. I said, 'It always knows my place.'

## Run

```sh
python3 -P -s main.py
cat /output/entry.txt
```

Python 3.13, standard library only.
